# Machine Learning Framework & Pipeline — HemoVision

This directory contains the modular Python packages, experiment configurations, training code, and test suites for the HemoVision machine learning research pipeline.

---

## Directory Architecture & Implemented Packages

```text
ml/
├── README.md                   # This document
├── requirements.txt            # Pinned Python dependency environment
├── configs/                    # Yaml configurations for experiments
├── notebooks/                  # Exploratory research notebooks
├── src/                        # Main modular Python source package
│   ├── data/                   # Dataset validation, schema checks, participant-isolated splitting
│   ├── preprocessing/          # Color calibration (Gray World, Reference White, LAB transform)
│   ├── segmentation/           # Palpebral conjunctiva ROI localization (HSV + LAB a* mask)
│   ├── quality/                # Research quality assessment (Laplacian blur variance, luminance, specularity)
│   ├── models/                 # Feature extraction (28 features), Ridge Hb Estimator, Conformal Intervals
│   ├── training/               # Model training pipelines & synthetic dataset generators
│   ├── evaluation/             # Model evaluation metrics & subgroup bias analysis
│   └── inference/              # Unified end-to-end InferencePipeline wrapper
└── tests/                      # Pytest unit testing suite (35+ passing tests)
    ├── test_schemas.py
    ├── test_segmentation.py
    ├── test_quality_and_preprocessing.py
    └── test_inference_and_models.py
```

---

## Safety & Research Boundaries

> [!CAUTION]
> **INVESTIGATIONAL RESEARCH SYSTEM ONLY**
> All predictions generated by `InferencePipeline` include explicit 95% conformal prediction intervals, engineering reliability scores, and non-diagnostic research disclaimers. Synthetic data is used exclusively for software testing and UI demonstrations.
