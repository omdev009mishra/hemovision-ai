# Mobile Application (Phase 7+ Roadmap)

This directory is designated for the cross-platform Flutter mobile client application planned in **Phase 7** and **Phase 8** of the HemoVision roadmap.

---

## Planned Capabilities
* **Guided Capture UI**: Real-time camera preview with eye alignment reticle and illumination intensity indicators.
* **On-Device Image Quality Gate**: Instant on-device evaluation of motion blur, exposure, and palpebral exposure adequacy before saving.
* **Edge ML Inference**: Local execution of conjunctiva segmentation and anemia risk estimation models using TFLite / ONNX Runtime.

*Note: Mobile application development will commence in Phase 7.*
