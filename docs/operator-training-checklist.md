# Operator training checklist

Default operator training status: **NOT_COMPLETED**.

An operator must demonstrate:

- [ ] Consent verification
- [ ] Pseudonymous participant-ID handling
- [ ] Camera positioning
- [ ] Lighting standardization
- [ ] Left/right eye labeling
- [ ] Quality rejection
- [ ] Segmentation review
- [ ] Metadata verification
- [ ] Secure transfer
- [ ] Withdrawal handling

The responsible institution documents training completion. Software does not infer completion from use.
