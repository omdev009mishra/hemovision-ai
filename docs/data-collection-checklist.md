# Data-collection checklist

## Before session

- [ ] Consent verified
- [ ] Participant ID created
- [ ] Study status allows collection
- [ ] Device ready
- [ ] Lighting ready
- [ ] Camera ready

## During session

- [ ] Left eye captured
- [ ] Right eye captured
- [ ] Required frames captured
- [ ] Quality checked
- [ ] Segmentation reviewed

## After session

- [ ] Lab reference linked
- [ ] Timestamp verified
- [ ] Metadata complete
- [ ] PII check complete
- [ ] Data transferred securely
- [ ] Session marked complete
